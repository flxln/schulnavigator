## 2. Änderungslog-Einträge (Pre-Mortem Fixes)

Die Pre-Mortem-Anpassungen wurden ohne Ausnahmen berücksichtigt:

- **¹ Panel feedback null-safe + running-first:** ✅ Korrekt im Render-Tree von `save-validate-panel.tsx` platziert.
- **² saveInProgress in den Test-Mocks:** ✅ In `studio-shell.test.tsx` und `studio-dashboard.test.tsx` integriert.
- **³ Dashboard-Render entkoppelt:** ✅ `initialLoading` Guard verhindert Flackern; bestehende Daten werden bei Refresh nur leicht gedimmt (`opacity-70`).
- **⁴ MpzCard-Tint-Vertrag geschärft:** ✅ Error-Hero in `studio-dashboard.tsx` nutzt saubere Kombination aus Default-Card und `border-l-error bg-error/5`.
- **⁵ Sun/Red nur im Dashboard:** ✅ `SaveValidatePanel` aggregiert Probleme zu einem Status ("Es gibt noch Fehler oder Warnungen"), Detail-Splitting verbleibt im Dashboard.
- **⁶ Refresh-Gating gegen Race:** ✅ "Erneut prüfen" Button in `ValidationCards` ist disabled solange `refreshDisabled = loading \|\| saveInProgress`.
- **⁷ Problemliste bleibt `<ul>`:** ✅ Die Problemliste in `studio-dashboard.tsx` behält die schlanke `<ul>`-Struktur.
- **⁸ Save-Panel als Custom-Tint-Banner:** ✅ Sauber gekapselt über die interne Hilfskomponente `TintBanner`.

## 3. Entscheidungstabelle

Die architektonischen und visuellen Vorgaben wurden konsequent eingehalten:
- Das Save-Panel nutzt das Inline-Layout unter der Top-Bar.
- Das Padding in `save-validate-panel.tsx` und `studio-shell.tsx` greift das neue Token `md:px-mpz-container-padding` auf.
- `MpzCard` wurde strikt ohne neue Props verwendet; visuelle Anpassungen erfolgen über `className`-Überschreibungen.

## 4. Scope

**Was ist im Code, das nicht im Plan steht?**
- In `save-validate-panel.tsx` wurde eine Hilfskomponente `TintBanner` abstrahiert, um Code-Duplizierung zwischen den Success/Error-Zuständen zu vermeiden. (Sauberes Refactoring).
- In `studio-dashboard.test.tsx` wurde ein voll ausgebautes `sampleReport` Objekt für das Mocking angelegt.

**Fazit:** Der Code entspricht dem Plan vollständig. Feature #208 kann als erfolgreich abgeschlossen betrachtet werden.
